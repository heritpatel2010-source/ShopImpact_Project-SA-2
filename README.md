# ShopImpact_Project
ShopImpact is a Python-based shopping application developed using Streamlit. It helps users make smarter and more eco-friendly shopping decisions by recording product details, brands and prices. The app estimates the CO₂ footprint of purchases, displays monthly spending and environmental impact, and suggests greener alternatives.
Python – Main programming language used to develop the application.
For my ShopImpact project, I used Python as the main programming language to develop the application and Streamlit to create the interactive web app and its user interface. I used Pandas to organise and analyse shopping records, along with lists and dictionaries to store purchase details and category-based CO₂ multipliers. I used functions to organise the code and perform calculations, while if-else conditions help calculate environmental impact and award achievement badges. The Date and Time module is used to record purchase dates and calculate monthly impact. I also used Matplotlib and Streamlit Charts to display shopping and CO₂ data visually. The CSV download feature allows users to download their purchase history, and Python Turtle Graphics is used to create eco-friendly visual designs for the project.
